# 5K视频封面编辑工作台

## 目标与发布流程

后台上传视频时只选择视频文件，不再上传封面。系统自动识别时长、方向并生成基础封面；新视频固定进入 `draft`（待发布）状态，内容类型默认选择 `18+`。管理员完成资料、精彩标签和封面后，再在视频编辑中改为 `published`。

## 使用流程

1. 在“视频管理”点击“封面编辑”，进入独立地址 `#cover/{videoId}`。
2. 顶部播放器可播放或拖动到任意时间，点击“截取当前帧”加入图片资源区。
3. 首次打开时，服务器从视频不同位置随机生成 10 张候选图并缓存。
4. 从资源区选择 2、3 或 4 张图片，选择均衡分栏、宫格、动感斜切或杂志主视觉，也可点击随机排版。
5. 输入中文标题并选择预设艺术字。模板已固定字体、颜色和描边，不提供容易产生低质量结果的细粒度色号设置。
6. 编辑器按视频方向生成竖版 `720×960`（3:4）或横版 `1280×720`（16:9）封面，并自动加入 5K 图标和“永久域名：5k.ag”。
7. 点击“保存为视频封面”，浏览器以 JPEG 质量 0.92 合成图片并上传，视频列表立即更新。

## 技术实现

- 管理端：React 19、Ant Design、Canvas 2D、hls.js。
- 服务端：Express、TypeScript、FFmpeg、multer。
- 候选帧存放在对应 HLS 目录的 `cover-assets` 子目录，已生成的默认候选图会复用。
- 待发布视频的播放地址仍是 20 分钟签名 URL；没有签名无法直接访问 HLS 清单或分片。
- 最终封面按日期目录保存，数据库仅记录新的 `thumbnail` 地址。

## API

- `GET /api/v1/admin/videos/:id/cover-assets`：生成或读取 10 张默认候选帧。
- `POST /api/v1/admin/videos/:id/cover-assets/capture`：按 `{ time }` 截取指定时间画面。
- `POST /api/v1/admin/videos/:id/cover`：multipart 上传字段 `cover`，保存合成封面。

以上接口均要求管理员 Bearer Token。
